# Road Collision Analysis

Analysis of **2023 road-collision records** linked with vehicle data, examining collision patterns and road-safety outcomes (including a breakdown by police force area).

## Approach
- Joined collision records with vehicle records for the year
- Cleaned and explored the data, then aggregated safety outcomes (e.g. `analysis_result_road_safety_by_force.csv`)
- Full analysis in the notebook

| Path | What it is |
